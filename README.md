# kb-parser

Parser di documenti e indice per una knowledge base, scritto in Python con la sola libreria standard.

Data una cartella di documenti in formati diversi (`.txt`, `.md`, `.csv`), il programma ne estrae
contenuto e metadati, li normalizza in una rappresentazione comune e costruisce un indice
consultabile e salvabile in JSON.
